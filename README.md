# 海洋清掃船 3Dアクション（River Cleanup Crew）

Three.js（r128）と Tailwind CSS を用いて構築された、ブラウザで動作する3D海洋・河川清掃アクションゲームです。  
双胴型の清掃船を操縦し、川を流れる漂流ゴミを船首コンベアや船員のタモ網で回収して、60秒以内に当日のノルマ達成と高評価（Aランク）を目指します。

## 主な機能

- **操船＆バランス物理**: 船体をタッチ＆左右スワイプで操船。急激な操作でロール角（傾き）が大きくなると水しぶきが発生し、限界角（19°）を超えると転覆します。
- **船員配置（コスト＆評価システム）**:
  - **なし（0名 / ¥0）**: 船首コンベアのみで回収。低コストのため最高評価（Aランク）を狙えます。
  - **左舷（1名 / +¥5,000）・両舷（2名 / +¥10,000）**: 網をタッチ＆外側へスワイプして離れたゴミを引き寄せ回収可能。人件費に応じて最終評価の基準が変動します。
- **河川環境・障害物**:
  - 凹凸のある護岸壁・道頓堀風のネオン看板ビル群。
  - 川を跨ぐ橋と水中橋脚（接触すると船体耐久 `HULL HP` が減少）。
- **デバッグパネル**: 画面右上の `DEBUG` ボタンからスクロール速度・残り時間・船員配置をリアルタイムに変更可能。

## ディレクトリ構成

```text
.
├── index.html        # エントリーHTML（HUD・ミッション画面・リザルト画面）
├── css/
│   └── style.css     # ベースレイアウト・タッチ操作制御スタイル
├── js/
│   ├── config.js     # 定数・ゴミ種別定義・アプリケーション状態管理
│   ├── world.js      # Three.jsシーン・水面・護岸・街並み・橋と橋脚
│   ├── ship.js       # 清掃船3Dモデル・船員・タモ網・水しぶきパーティクル
│   ├── trash.js      # 漂流ゴミのスポーン・物理移動・コンベア搬送ロジック
│   ├── ui.js         # HUD・耐久ゲージ・ミッション生成・ABC評価リザルトUI
│   └── main.js       # 入力処理・衝突判定・ゲーム進行・アニメーションループ
└── README.md
```

## ローカルでの起動方法

ビルドツール不要の静的HTML/JS構成のため、そのままローカルサーバーで配信して動作します。

```bash
# Python 3 を使用する場合
python3 -m http.server 8080

# Node.js (npx serve) を使用する場合
npx serve .
```

起動後、ブラウザで `http://localhost:8080` にアクセスしてください。
